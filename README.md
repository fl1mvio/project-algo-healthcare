Ruffier Test 💓

A modern application for performing and analyzing the Ruffier Test, a simple cardiovascular fitness assessment used to evaluate heart recovery and physical endurance. This project helps users calculate their Ruffier Index quickly and accurately through an intuitive interface.

Features
📊 Automatic Ruffier Index calculation
❤️ Heart rate tracking before and after exercise
⚡ Fast and user-friendly interface
📈 Fitness level interpretation based on results
📱 Responsive design for desktop and mobile
🧮 Real-time calculations and instant feedback
What is the Ruffier Test?

The Ruffier Test is a cardiovascular endurance test that measures how quickly the heart recovers after physical activity. It is commonly used in sports, fitness, and medical evaluations to estimate physical condition.
